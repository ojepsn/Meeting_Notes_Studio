## Documentation Principles

This documentation system follows a few simple rules:

- user guides explain how to complete real tasks
- reference pages explain what each feature or setting does
- architecture pages explain how the system is built
- development pages explain how to work on and release the app
- docs should be updated alongside meaningful feature changes whenever possible
