    Model

    Choose an OpenAI model

    Loading model guidance and pricing...

    Pricing is shown per 1 million tokens. In plain language, tokens are small chunks of text, so this is a standardized way to compare cost across models. For normal meeting notes, a single polish pass usually uses only a tiny fraction of that amount. As a rough guide, one page of text is about 500 words, which is approximately 750 tokens.

    Your API key is stored only in this browser so the app can call OpenAI directly from the client.
